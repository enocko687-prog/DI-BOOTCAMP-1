# React + TypeScript Exercises

A Vite-powered React and TypeScript app with hands-on exercises for typed
state, `useReducer`, `useContext`, `useRef`, generic components, and a to-do
list challenge with add, complete, delete, and filter actions. It also includes
reusable forms, tables, and typed data-fetching examples.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. The examples are on the home page.

## Run with VS Code Live Server

Live Server serves static files and cannot compile the React/TypeScript source.
Build the app first, then right-click `dist/index.html` and choose **Open with
Live Server**:

```sh
npm install
npm run build
```

The build uses relative asset paths so the generated page and its files work
when served from the `dist` folder.

## Check the project

```sh
npm run typecheck
npm run build
```
