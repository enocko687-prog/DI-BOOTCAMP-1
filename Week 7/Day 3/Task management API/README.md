# Task Management API

An Express API that stores tasks in `data/tasks.json`.

## Run

```powershell
npm install
npm start
```

The API listens on `http://localhost:3000` by default. Set the `PORT` environment variable to use a different port.

## Routes

- `GET /tasks` lists all tasks.
- `GET /tasks/:id` retrieves one task.
- `POST /tasks` creates a task. A non-empty `title` is required; `description` is an optional string and `completed` is an optional boolean (default `false`).
- `PUT /tasks/:id` updates a task. A non-empty `title` is required; `description` and `completed` are optional and retain their existing values when omitted.
- `DELETE /tasks/:id` deletes a task.

Task IDs are generated by the API. Missing tasks return `404`; invalid input returns `400`.

## Try with curl

```powershell
curl.exe http://localhost:3000/tasks

curl.exe -X POST http://localhost:3000/tasks `
  -H "Content-Type: application/json" `
  -d '{"title":"Prepare project","description":"Set up the API"}'

curl.exe -X PUT http://localhost:3000/tasks/TASK_ID `
  -H "Content-Type: application/json" `
  -d '{"title":"Prepare project","completed":true}'

curl.exe -X DELETE http://localhost:3000/tasks/TASK_ID
```
