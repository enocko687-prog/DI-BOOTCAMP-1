# Node.js Module Exercises

This folder contains the solutions for the Node.js module exercises.

## Exercise 1: CommonJS product module
- File: `Exercise 1/products.js`
- File: `Exercise 1/shop.js`
- Run:
  ```bash
  node "Exercise 1/shop.js"
  ```

## Exercise 2: ES6 module with average age
- File: `Exercise 2/data.js`
- File: `Exercise 2/app.js`
- Run:
  ```bash
  node "Exercise 2/app.js"
  ```

## Exercise 3: File read/write with CommonJS
- File: `Exercise 3/fileManager.js`
- File: `Exercise 3/app.js`
- Files:
  - `Exercise 3/Hello World.txt`
  - `Exercise 3/Bye World.txt`
- Run:
  ```bash
  node "Exercise 3/app.js"
  ```

## Exercise 4: Todo list with ES6 class module
- File: `todoApp/todo.js`
- File: `todoApp/app.js`
- Run:
  ```bash
  node "todoApp/app.js"
  ```

## Exercise 5: Custom module + lodash
- File: `math-app/math.js`
- File: `math-app/app.js`
- Run:
  ```bash
  cd math-app
  npm install lodash
  node app.js
  ```

## Exercise 6: Chalk package exercise
- File: `npm-beginner/app.js`
- Run:
  ```bash
  cd npm-beginner
  npm install chalk
  node app.js
  ```

## Exercise 7: Copy file and list directory
- File: `file-explorer/copy-file.js`
- File: `file-explorer/read-directory.js`
- Run:
  ```bash
  cd file-explorer
  node copy-file.js
  node read-directory.js
  ```

## Notes
- Some project setup commands may require using the Node launcher directly on Windows due to PowerShell execution policy restrictions.
- The chalk example was updated to use the installed version’s default export.
